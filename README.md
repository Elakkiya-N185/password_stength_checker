🔐 Password Strength Checker

📌 About the Project

Password Strength Checker is a simple Python mini-project that checks password strength and provides suggestions to improve it.

🎯 Objective

To help users understand password strength and learn how to create stronger passwords.

✨ Features

- Checks password strength.
- Identifies weak and moderate passwords.
- Provides suggestions to improve password strength.
- Uses Python conditions and string methods.

🛠️ Technologies Used

- Python 3
- Python IDLE

🚀 How to Run

1. Download the "password_checker.py" file.
2. Open the file in Python IDLE.
3. Press F5 to run the program.
4. Enter a test password.
5. View the password strength and suggestions.

📷 Sample Output

The program displays the password strength and suggestions based on the entered password.
